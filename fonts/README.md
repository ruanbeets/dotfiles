# Typography

- Application UI: Noto Sans 10 pt (9 pt for secondary labels).
- Terminal: JetBrainsMono Nerd Font 10.5 pt.
- KDE fixed-width text and KVitals: JetBrainsMono Nerd Font.
- Icons: Breeze Dark; cursor: Breeze, 24 px.

All fonts/icons come from official repository packages. No downloaded font blobs
or icon theme frameworks live in this repository. At 100% scaling on a 1440p
display, the terminal starts at 10.5 pt; adjust the profile if your DPI differs.
